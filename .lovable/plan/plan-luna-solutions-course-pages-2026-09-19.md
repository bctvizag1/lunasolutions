# Plan: Luna Solutions course pages

## Goal
Create five professional course detail pages that extend the existing Luna Solutions website and make each programme easier to understand and enquire about.

## Pages
- Networking & CCNA
- Azure Cloud
- Cyber Security
- Generative AI
- AI Agents

## Implementation
- Add one dedicated route for each course, using a shared course-page layout for consistent navigation, visual hierarchy, and mobile behavior.
- Give every page tailored introductory copy, course overview, key topics, practical learning outcomes, intended audience, and a clear counselling action.
- Add a distinct, relevant course image to each page and keep the imagery cohesive with the current polished Luna brand.
- Link all five programme cards on the home page to their matching detail pages while preserving the existing enquiry flow.
- Add complete page-specific search and social metadata for every new page.
- Preserve the existing AOS scroll animation approach and apply restrained reveals to page content.

## Validation
- Check all links, page content, images, animations, and enquiry actions.
- Review desktop and mobile layouts for overflow, readability, and visual consistency.
